## 👨‍💻 About Me

I am a software developer passionate about designing **clean, scalable full-stack web applications**, **data-driven machine learning pipelines**, and **interactive game systems**. I enjoy bridging solid backend architecture with polished, responsive user interfaces.

- 🏗️ **Full-Stack Architecture:** Building production-ready web platforms and microservices with **Next.js, React, TypeScript, and NestJS**.
- 🧠 **Data Mining & Applied AI:** Developing end-to-end ML pipelines, credit-risk scoring models, and macroeconomic regime forecasting with **Python, Scikit-Learn, LightGBM/XGBoost, SHAP, and Streamlit**.
- 🎮 **Game Systems & 3D Automation:** Engineering modular gameplay systems, boss AI state machines, and cross-scene data architectures in **Unity (C#)** alongside **Blender/FreeCAD MCP** automation workflows.
- ⚡ **Engineering Philosophy:** Clean code, type-safe contracts, modular architecture, and measurable performance.
